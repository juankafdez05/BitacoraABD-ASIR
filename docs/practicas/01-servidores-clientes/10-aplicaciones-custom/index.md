#Apliciones custom

## Aplicación de Alfredo

Aplicación escrita en python usando el framework Flask. Se conecta a una base de datos MongoDB utilizando el driver oficial PyMongo. Permite ver los documentos en las colecciones utorizadas de la base a la que se a conectado, filtrar por campos del documento y editar, añadir o eliminar documentos si se tiene permisos.
