#Apliciones custom

## Aplicación de Alfredo

Aplicación escrita en python usando el framework Flask. Se conecta a una base de datos MongoDB utilizando el driver oficial PyMongo. Permite ver los documentos en las colecciones utorizadas de la base a la que se a conectado, filtrar por campos del documento y editar, añadir o eliminar documentos si se tiene permisos.

###Enlaces:

- [Video](https://youtu.be/md58lL_RP6o)

- [Ficheros App](./app_mongo.tar.xz)


## Aplicación de Juan Carlos

Aplicación web desarrollada en Python utilizando el framework Flask. Se conecta a una base de datos PostgreSQL mediante el driver Psycopg2. Permite consultar las tablas accesibles para el usuario conectado, visualizar sus registros y filtrar por los valores de sus columnas.

- [Video](https://youtu.be/lGh-RiOFbaU)
